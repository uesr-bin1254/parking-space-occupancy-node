# 关键方案比较 — W04 系统设计（G3）

> 记录关键选型的比较与结论；**技术路线已确定：YOLO 视觉占用检测＋STM32 主控**（地磁/超声波为互补校验）。

## 一、检测方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| YOLO 摄像头（视觉占用检测） | 覆盖直观、可多车位、可配置不识别身份 | 计算需求高、依赖部署位/光照 | **采用（最终方案，主路线）** |
| 地磁 | 低功耗、耐候、可检测金属车辆 | 受环境铁磁干扰、单一易误判 | 采用（互补校验） |
| 超声波 | 测距直观、对非金属有效 | 受遮挡/角度影响 | 采用（互补校验） |
| 地磁+超声波双模 | 双模精度可达约99% | 仅感知、无画面证据 | 采用（校验融合） |
| 红外/ToF | 测距、成本低 | 易受阳光与尘土干扰 | 备选 |

## 二、主控方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| STM32 | 稳定、外设丰富、实时性强 | 需外接 Wi-Fi 模块 | **采用（最终方案，主控）** |
| ESP32 | 自带 Wi-Fi、开发成熟、成本低 | 性能有限 | 备选 |
| Arduino | 简单 | 需外接 Wi-Fi 模块 | 备选 |

## 三、通信方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| MQTT | 轻量、支持 QoS、适合传感器发布 | 需 broker | 采用 |
| HTTP 轮询 | 实现简单 | 实时性差、频繁轮询 | 备选 |

## 四、界面方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| Web Dashboard | 跨平台、部署方便 | 需服务器/静态托管 | 采用 |
| 本地 App | 体验好 | 开发维护成本高 | 备选 |

## 结论
- **最终方案**：摄像头 **YOLO 视觉占用检测（不识别身份）** → **STM32 主控（外接 ESP8266 Wi-Fi 模块）** → MQTT → SQLite → Web Dashboard。
- 地磁＋超声波双传感器作为低成本互补校验，弥补光照/遮挡下视觉误判。
- 该变更经团队＋教师评审确认，记入 Change Log（CH03，生效版本 v1.1）；接口 I01–I04、BOM 与测试计划已相应更新。
