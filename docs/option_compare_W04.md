# 关键方案比较 — W04 系统设计（G3）

> 记录关键选型的比较与结论；YOLO＋STM32 作为候选路线标注（待评估，未定稿）。

## 一、传感器方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| 地磁 | 低功耗、耐候、可检测金属车辆 | 受环境铁磁干扰、单一易误判 | 采用（与超声波融合） |
| 超声波 | 测距直观、对非金属有效 | 受遮挡/角度影响 | 采用（与地磁融合） |
| 地磁+超声波双模 | 户外全天气、双模检测精度可达约99% | 需双传感融合逻辑 | 本项目基线（双传感融合） |
| 红外/ToF | 测距、成本低 | 易受阳光与尘土干扰 | 备选 |
| YOLO 摄像头 | 可多车位、可配置不识别身份 | 计算需求高、部署位/光照依赖 | **候选路线（待评估）** |

## 二、主控方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| ESP32 | 自带 Wi-Fi、开发成熟、成本低、可借用 | 性能有限 | 采用（基线） |
| STM32 | 稳定、外设丰富、实时性强 | 需外接通信（Wi-Fi 模块） | **候选路线（待评估，可替代/配合 ESP32）** |
| Arduino | 简单 | 需外接 Wi-Fi 模块 | 备选 |

## 三、通信方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| MQTT | 轻量、支持 QoS、适合传感器发布 | 需 broker | 采用 |
| HTTP 轮询 | 实现简单 | 实时性差、频繁轮询 | 备选 |

## 四、界面方案
| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| Web Dashboard | 跨平台、部署方便 | 需服务器/静态托管 | 采用 |
| 本地 App | 体验好 | 开发维护成本高 | 备选 |

## 结论
- 基线：**地磁＋超声波 → ESP32 → MQTT → SQLite → Web Dashboard**。
- 候选：**YOLO（视觉占用检测）＋ STM32（主控）**待评估，是否采纳及最终架构待评审后确定；若采纳将相应更新接口 I01–I03、BOM 与测试计划，并经 Change Log 记录。
