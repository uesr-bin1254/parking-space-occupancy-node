# 问题陈述 — W02 问题定义（G1）

- **项目**：3.1 停车场占用监测节点
- **版本**：v0.1（待 G1 评审确认）

## 用户与场景
- **主要用户**：校园停车场管理方、开车师生/访客、校园设施管理部门。
- **场景**：高峰时段（上下课/活动）校园停车位紧张，司机难以获知各车位是否空闲，常出现找位耗时、排队绕行；管理方缺少实时的车位占用信息来引导与决策。

## 问题陈述（约150–250字）
在校园停车场的高峰时段，现有停车信息无法实时反映每个车位的占用/空闲状态，导致司机找位耗时、车辆在停车场内反复绕行，管理方也缺少可用于引导与调度的实时数据。本项目拟开发一个**停车场占用监测节点**：在不识别车辆身份的前提下，监测单个车位的占用/空闲状态，并将状态通过无线方式上传，供 Web 界面实时显示。预期为管理方与司机构建一套低成本、隐私友好的车位占用可视化能力，为后续停车引导与运营调度提供数据基础。

## 范围内 / 范围外
- **范围内**：单车位占用/空闲检测；状态经 Wi-Fi/MQTT 上传；Dashboard 实时显示占用与空余数；占用率历史记录；断网自动重连。
- **范围外**：不识别车辆身份/车牌；不提供车位导航与引导；不涉及收费管理；不做多停车场统一调度。

## 候选成功指标（阈值待 W03 冻结）
- 占用检测准确率 ≥90%（判成功比例）
- 空余数更新时延：界面最大 ≤5s
- 断网重连成功率 100%（判成功比例）

## 来源与证据
- 问题描述依据：管理方调研整理 EV-01、现场观察调研整理 EV-02（见 docs/）；正式访谈/现场实测数据待补。
- 公开来源：大连理工大学《基于大数据的大学校园停车系统规划》（高峰时段与分布不均）；西安建筑科技大学《智能停车场管理系统技术方案》（车位级状态感知与引导）；多地停车管理答复（配建不足、瞬时高峰）。
- 管理方明确需求/排除项：见 EV-01 结论。
