# 停车场占用监测节点（Parking Space Occupancy Monitoring Node）

> UL–LICHPU 智能校园 · 主题3 可持续交通与停车 · 项目3.1 · 团队工程（15 ECTS）

本仓库用于记录「停车场占用监测节点」团队项目的逐周工作日志（Git 提交历史即工作日志证据），并纳入每周报告与过程产物。

## 技术方案（统一口径）

地磁 + 超声波双传感器融合 → ESP32 边缘处理 → MQTT/Wi-Fi → SQLite 存储 → Web Dashboard。
全程**不识别车辆身份**（隐私友好），规避摄像头方案的隐私与合规问题。

- 成员分工：A 协调与文档 / B 硬件与传感 / C 软件与数据 / D 测试与验证
- 需求基线：R01–R06（详见 `weekly_reports/W03_需求规格.docx` 与需求文档）
- 接口：I01 地磁→MCU（I2C，100ms）；I02 超声波→MCU（200ms）；I03 MCU→MQTT→SQLite/Dashboard
- 当前进度：**第 8 周**（中期工程评审 G5）

## 目录结构

## 使用说明

- 每周结束时在本目录更新 `work_logs/Wxx.md` 并 `git add` + `git commit`，提交信息遵循 `Wxx: <标题> — <一句话说明>`。
- 成员个人 Log 填写在各周工作日志的「个人 Log」区，保留个人证据路径。
- 实验数据以 `real / simulated / public` 明确标注来源，缺失项不编造。

## 提交约定

- 默认分支：`main`
- 每条提交对应一周工作，提交历史即团队工作日志
- 里程碑：W07 端到端原型 → W10 数据证据 → W12 验收冻结 → W14 最终档案（当前推进至 W08）
